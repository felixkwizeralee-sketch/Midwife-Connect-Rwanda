# Midwife Connect Rwanda — GitHub Pages

This project is configured for the repository:
`Midwife-Connect-Rwanda`

## Replace the existing repository

1. Open the `Midwife-Connect-Rwanda` repository on GitHub.
2. Delete the old website files, or replace all repository contents with these files.
3. Upload/commit the files in this project to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. Push to `main` and wait for the **Deploy to GitHub Pages** workflow to finish.

The site will use this base path:
`/Midwife-Connect-Rwanda/`

## Important

This GitHub Pages version is a static frontend. Registration/login data is stored in the visitor's browser using localStorage, so it is not a shared online database. The AI assistant and contact API endpoints require the Node/Express server and will not work on GitHub Pages alone.
